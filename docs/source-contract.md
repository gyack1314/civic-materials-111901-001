# 本地来源契约

资料源有市站与文件站两个访问组。GET /policies 返回组成员、滚动窗口上限和演练时钟；Host 的主机名参与分组，端口不参与。市站 127.0.0.1 与 localhost 共用 10 秒内两次产品访问，文件站 127.0.0.2 允许 5 秒一次。/policies、/robots.txt 与演练控制不扣额度，但被拒的产品访问也计入来源的访问记录。
GET /topics/{专题名} 返回 HTML，rel=document 表示资料链接；GET /redirect/{名称} 转向相同端口文件站；GET /files/{名称} 返回原件。阶段 1 的市站 robots 禁止 /files/，文件站授权不由市站代替。主机、路径和每一跳均要按实际来源解释。来源无强制登录。
Retry-After 为演练时钟中的秒数，时钟仅由控制接口推进。等待可查询 /health 的来源时间，不用真实长时间等待。来源记录原始请求头，便于核对访问是否先于授权。文件服务器实际监听所有本地地址。

演练来源由 Python 标准库 HTTP 服务启动，默认端口 8765。GET /health 可查询来源时间与阶段；POST /__admin/advance 接收 seconds、phase 推进本地情形；GET /__admin/log 回查实际请求。这些控制只供操作员调试来源，不能替代产品从正常入口取得资料。来源进程重启会清空其演练状态；采集端自己的保存目录由产品独立管理。
